# Local configuration

Store the inspected controller profile as `fc_profile.json` and the reviewed,
current thrust-cell calibration as `loadcell_calibration.json` here. Both are
ignored by Git. See [setup](../README.md) before running hardware.

`tools/fc_profile.json` and `examples/reference_loadcell_calibration.json` retain
historical reference data for tests and provenance; neither establishes the
configuration or calibration of a newly connected rig.
